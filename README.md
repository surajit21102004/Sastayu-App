# Sastayu

Sastayu is an on-demand home services platform with mobile client applications and an Express/MySQL backend.

## Workspace Structure

```
1Sastayu/
├── app/                  # React Native / Expo Mobile Application
├── be/                   # Node.js + Express + MySQL Backend API
├── Sastayu-Brand-Kit/    # Official Branding Assets (Logos, Icons, Social Media)
└── Screen App/           # UI/UX Reference Screens (Users & Workers)
```

## Quick Start

### Backend (`/be`)
```bash
cd be
npm install
# Configure .env based on .env.example
npm run dev
```

### Mobile App (`/app`)
```bash
cd app
npm install
npm start
```
