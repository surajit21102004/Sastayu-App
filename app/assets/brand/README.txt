SASTAYU - BRAND KIT
===================

COLOURS
  Blue    #1E40AF   (main brand colour, buttons, backgrounds)
  Yellow  #FBBF24   (accent: the S pipe, tags, highlights)
  Navy    #0F172A   (text on light backgrounds, text on yellow)
  White   #FFFFFF
  Rule: use navy text on yellow, white text on blue. Never white text on yellow.

FONT
  Poppins (free on Google Fonts). Bold for the wordmark and headlines.
  In all files the text is already converted to shapes, so you do not need to install it.

FOLDERS
  01-Logo       Main logos (SVG = scalable/print, PNG = ready to use)
  02-App-Icon   App Store / Play Store icon, all sizes, Android adaptive layers
  03-Website    Header logos, favicons (ico + png), apple-touch-icon, share image (OG)
  04-Facebook   Profile picture, cover, post
  05-Instagram  Profile picture, post
  06-LinkedIn   Profile picture, banner
  07-X-Twitter  Profile picture, header
  08-YouTube    Profile picture, banner (text kept in the centre safe area)

NOTES
  - app-icon-1024.png has square corners on purpose. The App Store and Play Store round it for you.
  - Banners show [YOUR WEBSITE] and [YOUR PHONE] as placeholders. Replace them before posting.
  - The headline "One App with 100+ Solutions" should match what you offer at launch.
